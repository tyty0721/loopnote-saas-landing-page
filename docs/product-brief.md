# LoopNote product brief — official concept

Version 1.0 · 2026-10-01. These are fictional product settings, not an available commercial service.

| Fact | Setting |
|---|---|
| Product | LoopNote |
| Audience | Project owners in 5–50-person remote or hybrid teams |
| Problem | Meeting notes take effort to organize; decisions and follow-up work are scattered; owners and due dates can be unclear |
| Concept | Organize meeting content into a summary, decisions, action items, owners and due dates |
| Core message | Make it clear what was decided and who will do what next |
| Free | $0/month, 5 meetings per month |
| Pro | $12 per user per month |
| Team | $29 per user per month |
| Target tools | Notion, Slack and Jira as concept integration ideas; none connected |
| Brand tone | Clear, professional, restrained |
| Example data | Three preset meetings, each with three tasks; fictional names and meeting records |

The page visibly labels itself “Concept website · Fictional product” / “概念网站 · 虚构产品”. The interface illustration and interactive workspace are explicitly preset examples. Plan cards describe conceptual capabilities without adding unsupported quotas. No customer testimonials, customer counts, measured productivity claims, security certification, data retention promise, refund policy or competitor comparison is included.

The deliverable is a marketing page and local interaction prototype. It does not record, transcribe, invoke a model, connect calendars or integrations, create accounts, charge fees or store real user data. Task changes last only in page memory. Language changes preserve current selection and tasks. Refresh or reset restores the examples.
