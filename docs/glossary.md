# English / 简体中文 terminology

| English | 中文 | Use |
|---|---|---|
| meeting summary / summary | 会议摘要 / 摘要 | Discussion context and outcome |
| decision | 决策 | What the team agreed |
| action item | 行动项 | A concrete piece of follow-up work |
| owner | 负责人 | Person assigned to a task |
| due date | 截止日期 | Date attached to a task |
| next steps | 下一步 / 后续任务 | Human-facing expression for follow-up |
| workspace | 工作区 | Container for meeting records |
| sample workspace | 示例工作区 | Preset local interface |
| preset data | 预置数据 | Fixed fictional examples |
| reset demo | 重置演示 | Restore original meetings and task states |
| concept integration | 概念集成 | Desired workflow idea, not a live connection |
| plan | 套餐 | Fictional pricing option |
| try the demo | 体验演示 | Navigate to the local workspace |
| remote / hybrid team | 远程 / 混合办公团队 | Audience setting |
| prototype | 原型 | A sample work item in the preset meeting |

Keep product names LoopNote, Free, Pro, Team, Notion, Slack and Jira unchanged in both languages. Fictional participant names are kept in Latin script. Chinese dates use month/day wording; all dates and task states correspond to the same example in English.
