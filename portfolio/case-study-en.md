# Responsive SaaS Landing Page with Chinese Localization

Self-initiated concept website for LoopNote, a fictional meeting productivity product. Designed for project owners in remote or hybrid teams who need a clearer view of meeting summaries, decisions and follow-up tasks.

The page includes an HTML/CSS product illustration, three working sample meetings, task completion controls, a reset action, a three-plan comparison, explanation dialogs and an accessible FAQ. Complete English and Simplified Chinese copy uses a shared content structure. The responsive layout provides a collapsible mobile menu and rearranges the sample workspace for smaller screens.

Built with maintainable HTML, CSS and plain JavaScript. All runtime resources are local: the page can open directly from its folder without a build step, API key or external font service. The deliverable includes editable source, bilingual copy documents, a product brief, design notes, a terminology table and a documented independent client-revision exercise.

The demo uses preset fictional data. It does not record or transcribe meetings, invoke an AI model, create accounts, charge payments or connect to Notion, Slack or Jira. No conversion or productivity result is claimed. Browser validation results and remaining review boundaries are recorded in `docs/qa-report.md`.

Portfolio media must be captured from the actual running website. The official page uses Pro $12; the separate simulated client revision uses $15 and is documented as an exercise.
